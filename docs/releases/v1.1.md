# Pwint Thit v1.1

Release version: **1.1.0**. This release preserves the current system as the baseline before the planned v1.2 redesign.

## Included

Phases 1–20: catalog and packaging, suppliers, purchases and historical exchange rates, shipments and landed costs, receiving and inventory movements, batch and expiry tracking, POS and invoices, customer credit and payments, damage and returns, operating expenses, Dashboard and 14 reports.

Recent improvements include persistent sidebar scroll position, clearer business navigation, user guidance, explicit warehouse setup guidance, clearer fixed packaging conversions, and exchange quotes such as 100 INR = 4,450 MMK with backend exact-decimal normalization. Authorized users can edit a new purchase's rate without overwriting saved quotes or posted purchases.

## Boundaries

This is the current implemented baseline, not a claim that every usability issue is resolved. The user has requested a broad redesign for v1.2; scope will come in the next prompt. Existing transaction history, stock movements, permissions and exact financial calculations must be considered during that redesign.

## Validation

`make check` passed, including Go checks, frontend lint and build. All 24 real-stack browser tests passed. `make up` refreshed localhost:8088; services are healthy and the deployed browser title is Pwint Thit v1.1. Business changes preceding version labeling also passed PostgreSQL integration tests.
